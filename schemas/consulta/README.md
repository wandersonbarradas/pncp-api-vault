# Schemas da API de Consulta PNCP

Schemas normalizados a partir de `components.schemas` da OpenAPI `api/consulta`.

Use estes arquivos para perguntas sobre payloads públicos de consulta. Não assuma equivalência com os schemas da superfície `api/pncp`.

Fonte: <https://pncp.gov.br/api/consulta/v3/api-docs>, verificada em 2026-05-03.

# Schemas OpenAPI PNCP

Arquivos normalizados a partir de `components.schemas` da OpenAPI pública do PNCP.

Use estes arquivos para consultar campos de DTOs sem abrir o Swagger inteiro. Endpoints em `sessoes/` apontam para estes schemas quando a operação referencia um componente OpenAPI nomeado.

Fonte verificada: <https://pncp.gov.br/pncp-api/v3/api-docs> em 2026-10-07.

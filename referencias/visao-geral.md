# Visão Geral

Este vault organiza a API PNCP por sessão funcional para consulta humana e por LLM.

## Ponto de Partida Recomendado

- Abra [index.md](../index.md) para navegação principal.
- Use [mapas/dominios.md](../mapas/dominios.md) para navegar por tema funcional.
- Use [mapas/operacoes.md](../mapas/operacoes.md) quando a busca for por método ou nome de operação.
- Use [referencias/cobertura.md](./cobertura.md) para entender a origem do material.

## Escopo

- O vault contém documentação normalizada de endpoints e operações.
- Ele não inclui logs de manutenção, revisões de wiki ou material intermediário de ingestão.
- Os arquivos em `sessoes/` são a camada principal de consulta.

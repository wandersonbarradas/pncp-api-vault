# Índice Rápido para LLM

Use este arquivo para localizar a sessão e o arquivo antes de abrir documentação detalhada.

## Rotas de Busca

- Se a pergunta cita um path, busque o trecho do path nesta página primeiro.
- Se a pergunta cita `api/consulta`, dados publicados, consulta pública ou `numeroControlePNCP`, comece por [consulta](./consulta.md).
- Se a pergunta cita um path de `api/consulta`, use [rotas-consulta-compactas](./rotas-consulta-compactas.md).
- Se a pergunta cita um domínio, abra o índice da sessão em `sessoes/<sessao>/index.md`.
- Só abra o arquivo detalhado do endpoint depois de identificar a operação candidata.
- Para operações CRUD de tabelas de domínio, comece por Domínios e Tabelas no `index.md` e consulte `referencias/tabelas-de-dominio-pncp.md` para códigos/regras.
- Para contratação, atas, contratos, termos e PCA, comece por Fluxos Operacionais no `index.md`.
- Para perguntas em linguagem natural, use também `mapas/como-consultar.md`.
- Para campos de resposta da API de Consulta, use [schemas-consulta](./schemas-consulta.md); para `api/pncp`, use [schemas](./schemas.md).

## Superfícies

- `api/consulta`: consulta pública de dados publicados; índice: [consulta](../consulta/index.md); rotas: [rotas-consulta-compactas](./rotas-consulta-compactas.md); schemas: [schemas-consulta](./schemas-consulta.md).

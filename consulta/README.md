# API de Consulta PNCP

Superfície pública de leitura documentada pelo Swagger `api/consulta`.

Fonte: <https://pncp.gov.br/api/consulta/v3/api-docs>

## Quando Usar

- Use `api/consulta/v1` para leitura pública de dados publicados no PNCP.
- Use `api/pncp/v1` para manutenção, registro e sub-recursos documentados nessa superfície.
- Não assuma que os schemas de `api/consulta` e `api/pncp` são iguais.
